# 오전·오후 배경화면 변경

학습 날짜: 2026-09-09 (수)

PowerShell로 실행 시각을 확인하고 오전과 오후에 맞는 배경화면을 적용하는 실습입니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `Set-AM-PMWallpaper.ps1` | 현재 시각에 따라 배경화면을 변경하는 스크립트 |
| `am.png` | 오전용 배경화면 |
| `pm.png` | 오후용 배경화면 |
| `wallpaper.log` | 적용 시각과 이미지 경로를 기록하는 실행 로그. Git에서 제외 |

## 동작 방식

1. PC의 현재 시각을 확인합니다.
2. 00:00~11:59에는 `am.png`, 12:00~23:59에는 `pm.png`를 선택합니다.
3. 이미지 파일이 있는지 확인한 뒤 Windows API로 배경화면을 적용합니다.
4. 적용에 성공하면 `wallpaper.log`에 시각과 이미지 경로를 기록합니다.

이미지와 로그 경로는 `$PSScriptRoot`를 기준으로 찾습니다. 스크립트와 이미지를 같은 폴더에 두면 폴더를 이동해도 경로를 다시 지정할 필요가 없습니다.

## 실행 방법

Windows PowerShell에서 다음 명령을 실행합니다.

```powershell
cd C:\ai-starter\2026-09\09-09\wallpaper
powershell -NoProfile -ExecutionPolicy Bypass -File .\Set-AM-PMWallpaper.ps1
```

실행하면 실제 Windows 바탕화면이 변경됩니다. `am.png`와 `pm.png`가 스크립트와 같은 폴더에 있어야 합니다.

## 자동 실행과의 차이

스크립트는 실행할 때 한 번만 배경화면을 변경합니다. 켜 두어도 정오에 자동으로 다시 실행되지는 않습니다.

시간대에 맞춰 자동으로 변경하려면 Windows 작업 스케줄러에 실행 시간을 별도로 등록해야 합니다. 등록된 작업이 있다면 폴더 이동 후 해당 작업의 스크립트 경로도 확인합니다.

## 오류 확인

- `Wallpaper file not found`: 같은 폴더에 선택된 이미지 파일이 있는지 확인합니다.
- `SystemParametersInfo failed`: 출력된 Windows 오류 코드를 확인합니다.
- 로그 저장 실패: 스크립트 폴더에 파일을 쓸 수 있는지 확인합니다. 배경화면 적용 후 로그 저장만 실패할 수도 있습니다.
