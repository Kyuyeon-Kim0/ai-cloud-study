# 목표
wallpaper 폴더의 이미지 파일 정보를 표로 정리한다.

# 대상
C:\ai-starter\wallpaper

# 작업
- dir 로 폴더의 파일 목록 확인
- 파일별 정보 수집: 파일명, 용량, 바이트, 확장자, 해상도, 작성/수정 시간
- 표로 정리
- 표 맨 아래에 전체 용량 합계 행 추가

# 출력 형식
아래 표 형식을 그대로 따를 것
| 파일명 | 용량 | 바이트 | 확장자 | 해상도 | 작성 시간 |
|---|---|---|---|---|---|
| am.png | 4.95 MB | 5,195,685 | PNG | 2752 x 1536 | 2026-09-03 15:13:51 |

# 제한
- 파일 이동·이름변경·삭제 금지
- 조회만 할 것
