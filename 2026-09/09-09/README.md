## 핵심 이해

### 생성형 LLM과 Codex

- 생성형 LLM은 입력 및 출력 토큰 제한이 있다.
- Codex는 코드 에이전트로서 자연어 명령을 바탕으로 코드를 작성하고 수정한다.
- 작업 지시서를 Markdown 파일로 작성하면 작업의 일관성과 표준화에 도움이 된다.
- 코드 작업은 Python, PowerShell 등 사용할 언어를 명확히 알려주면 좋다.

### PowerShell 시스템 점검

- 컴퓨터 자원은 운영체제에 맞는 명령어로 조회할 수 있다.
- 여러 PowerShell 명령은 `.ps1` 파일로 저장하여 실행할 수 있다.
- 조회한 시스템 정보를 바탕으로 보고서를 만들 수 있다.
- `system_monitor.ps1`을 작성하고 작업 지시서에서 실행했다.

## 실습 파일

- `system_monitor.ps1`: 컴퓨터 성능 및 시스템 정보 조회
- `system-info.ps1`: 시스템 정보 확인
