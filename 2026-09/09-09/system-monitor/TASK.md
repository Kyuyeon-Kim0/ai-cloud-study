# TASK: 시스템 정보 조회

## 작업 목적
- 현재 PC의 시스템 정보를 확인한다.
- 기존 PowerShell 스크립트를 실행하고 결과를 확인한다.

## 실행 파일
- 파일: `system_monitor.ps1`
- 위치: `C:\ai-starter\system-monitor`

## 실행 명령
powershell -ExecutionPolicy Bypass -File .\system_monitor.ps1

## 작업 순서
1. `system_monitor.ps1` 파일이 존재하는지 확인한다.
2. 실행 파일의 내용을 확인한다.
3. 지정된 명령으로 스크립트를 실행한다.
4. 출력된 시스템 정보를 확인한다.
5. 정상 실행 여부와 결과를 보고한다.

## 작업 제한
- 파일 수정 금지
- 프로그램 및 패키지 설치 금지
- 시스템 및 PowerShell 설정 변경 금지
- 파일 삭제 및 이동 금지

## 오류 발생 시
- 임의로 수정하지 않는다.
- 오류 메시지와 발생 단계를 먼저 보고한다.
- 추가 지시를 기다린다.

## 완료 조건
- 파일 확인 완료
- 스크립트 실행 완료
- 출력 결과 확인 완료
- 실행 결과 보고 완료
