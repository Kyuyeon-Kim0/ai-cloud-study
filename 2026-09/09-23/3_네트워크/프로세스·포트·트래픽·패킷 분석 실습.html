확인 순서 요약

궁금한 것도구핵심 확인
프로그램이 살아 있나?htopPID / CPU / MEM / Command
포트가 열려 있나?ss -lntpLISTEN
누가 연결했나?ss -tnp출발지 IP·포트
어느 IP와 많이 통신하나?iftop -i eth0송수신량
실제 패킷은?tcpdumpICMP / TCP / IP
MAC까지?tcpdump -eEthernet Header
IP↔MAC 대응?ip neighNeighbor Table
나중에 분석?tcpdump -wpcap 저장
핵심 흐름:
프로세스 확인 → 포트 확인 → 연결 확인 → 트래픽량 확인 → 패킷 확인 → MAC/Neighbor 확인 → 필요하면 pcap 저장
