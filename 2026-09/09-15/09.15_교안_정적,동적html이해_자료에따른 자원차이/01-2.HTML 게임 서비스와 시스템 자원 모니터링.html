1. 실습 목표

네트워크 이론보다 먼저 서비스 운영과 모니터링을 경험합니다.

서비스 실행 → 사용자 활동 → 로그 → 자원 측정 → 상태 판단

5. server.py 만들기

FastAPI/Flask 없이 Python 기본 모듈을 사용합니다. ThreadingHTTPServer로 여러 요청을 처리하고 CSV 기록 충돌을 줄이기 위해 Lock을 사용합니다.

from http.server import ThreadingHTTPServer, SimpleHTTPRequestHandler
from datetime import datetime
import socket, json, csv, os, threading

LOG_FILE = "game_log.csv"
log_lock = threading.Lock()

class GameHandler(SimpleHTTPRequestHandler):
    def do_GET(self):
        if self.path == "/":
            self.path = "/index.html"
        return super().do_GET()

    def do_POST(self):
        if self.path != "/log":
            self.send_error(404)
            return
        try:
            length = int(self.headers.get("Content-Length", 0))
            data = json.loads(self.rfile.read(length))

            with log_lock:
                exists = os.path.exists(LOG_FILE)
                with open(LOG_FILE,"a",newline="",encoding="utf-8-sig") as f:
                    w = csv.writer(f)
                    if not exists:
                        w.writerow(["datetime","nickname","client_ip","event","score"])
                    w.writerow([
                        datetime.now().strftime("%Y-%m-%d %H:%M:%S.%f")[:-3],
                        data.get("nickname",""),
                        self.client_address[0],
                        data.get("event",""),
                        data.get("score","")
                    ])

            self.send_response(200)
            self.end_headers()
        except Exception as e:
            print("LOG ERROR:", e)
            self.send_error(500)

def get_ip():
    s=socket.socket(socket.AF_INET,socket.SOCK_DGRAM)
    try:
        s.connect(("8.8.8.8",80))
        return s.getsockname()[0]
    except OSError:
        return "127.0.0.1"
    finally:
        s.close()

ip=get_ip()
server=ThreadingHTTPServer(("0.0.0.0",8000),GameHandler)

print("="*45)
print("HTML GAME SERVER")
print("사용자 2 접속 주소")
print(f"http://{ip}:8000")
print("종료 : Ctrl + C")
print("="*45)

try:
    server.serve_forever()
except KeyboardInterrupt:
    server.server_close()
    print("\nServer Stop")

10. Codex 작업

codex
현재 Windows PC의 시스템 자원을 기록하는 monitor.py 파일만 만들어줘.

[목적]
HTML 게임 서비스의 사용자 수가 증가할 때
사용자 1(서버) PC의 자원 변화를 관찰한다.
클라우드 및 시스템관리자 초보 교육용이다.

[사용]
psutil + Python 기본 모듈만 사용

[1초마다 측정]
- datetime
- cpu_percent
- memory_percent
- memory_used_mb
- bytes_sent_total
- bytes_recv_total
- bytes_sent_1sec
- bytes_recv_1sec

bytes_sent_1sec와 bytes_recv_1sec는
현재 누적값 - 1초 전 누적값으로 계산한다.

[PowerShell 화면 출력]
CSV용 전체 리스트를 그대로 print하지 말 것.
PowerShell에는 초보자가 바로 읽을 수 있도록 다음 5개만 한 줄로 출력한다.

- 시각(HH:MM:SS)
- CPU 사용률 %
- RAM 사용률 %
- 최근 1초 송신량
- 최근 1초 수신량

반드시 다음 형식으로 출력한다.

13:25:01 | CPU 13.2% | RAM 45.6% | SEND 441 B/s | RECV 485 B/s

화면에는 bytes_sent_total, bytes_recv_total, memory_used_mb를 표시하지 않아도 된다.
이 상세값들은 CSV에만 저장한다.

[저장]
resource_log.csv에 계속 추가한다.
기존 파일을 삭제하거나 덮어쓰지 않는다.
처음 생성할 때만 헤더를 기록한다.

[조건]
- 화면에도 1초마다 측정값 출력
- Ctrl+C로 정상 종료
- Windows 환경
- 최대한 짧고 초보자가 읽기 쉽게 작성
- 함수/클래스는 가능하면 사용하지 않기
- FastAPI/Flask 사용 금지
- index.html과 server.py 수정 금지
- monitor.py만 생성
- 마지막에 python -m py_compile monitor.py 로 문법 검사

12. 모니터링 화면 읽는 방법

PowerShell에서는 복잡한 리스트 대신 다음처럼 핵심 값만 확인합니다.

13:24:58 | CPU 25.2% | RAM 45.6% | SEND 87 B/s   | RECV 90 B/s
13:24:59 | CPU  9.3% | RAM 45.7% | SEND 110 B/s  | RECV 132 B/s
13:25:00 | CPU  7.3% | RAM 45.6% | SEND 8465 B/s | RECV 11749 B/s
13:25:01 | CPU 13.2% | RAM 45.6% | SEND 441 B/s  | RECV 485 B/s
표시뜻관리자 관점
CPU현재 CPU 사용률처리 작업이 증가하는지 확인
RAM현재 메모리 사용률메모리 사용이 계속 증가하는지 확인
SEND최근 1초 동안 보낸 데이터서비스가 외부로 보내는 통신량 변화 관찰
RECV최근 1초 동안 받은 데이터서비스가 받아들이는 통신량 변화 관찰
예: 13:25:00에 SEND와 RECV가 갑자기 증가했다면, 같은 시간의 game_log.csv를 확인하여 사용자들이 어떤 행동을 했는지 비교합니다.

주의: 이 값들은 게임 서버 프로세스 하나만의 사용량이 아니라 사용자 1 PC 전체의 시스템 자원과 네트워크 사용량입니다. 다른 프로그램의 활동도 값에 포함될 수 있습니다.
