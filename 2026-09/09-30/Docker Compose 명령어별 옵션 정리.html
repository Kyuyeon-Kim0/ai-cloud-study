DOCKER COMPOSE COMMAND

docker compose 공통 옵션

모든 Docker Compose 명령에 공통으로 적용할 수 있는 전역 옵션입니다.

Usage
docker compose [OPTIONS] COMMAND

옵션

옵션기본값설명
--all-resources - 서비스가 직접 사용하지 않는 리소스까지 포함
--ansi auto ANSI 제어문자 출력 방식: never / always / auto
--compatibility - 이전 Compose 동작과의 호환 모드
--dry-run - 실제로 변경하지 않고 수행할 작업을 미리 확인
--env-file - 기본 .env 대신 사용할 환경변수 파일 지정
-f, --file - 사용할 Compose 파일 지정
--parallel -1 동시에 처리할 작업 수 제한. -1은 제한 없음
--profile - 활성화할 profile 지정
--progress - 진행 출력 방식 지정: auto / tty / plain / json / quiet
--project-directory - 프로젝트 기준 디렉터리 지정
-p, --project-name - Compose 프로젝트 이름 지정

실행 예시

docker compose -f compose.dev.yaml up -d
docker compose -p myproject ps
docker compose --dry-run up -d
DOCKER COMPOSE COMMAND

docker compose up

서비스의 컨테이너를 생성하고 시작합니다. Compose에서 가장 많이 사용하는 명령입니다.

Usage
docker compose up [OPTIONS] [SERVICE...]

옵션

옵션기본값설명
-d, --detach - 백그라운드에서 실행
--build - 시작 전에 이미지를 빌드
--force-recreate - 설정 변경이 없어도 컨테이너를 강제로 다시 생성
--no-recreate - 기존 컨테이너가 있으면 다시 생성하지 않음
--no-build - 이미지를 빌드하지 않음
--pull policy 실행 전 이미지 pull 정책 지정: always / missing / never
--remove-orphans - Compose 파일에 없는 기존 서비스 컨테이너 제거
--scale - 특정 서비스를 지정한 개수만큼 실행
--wait - 서비스가 running/healthy 상태가 될 때까지 기다림
--wait-timeout - --wait 최대 대기 시간 지정
--no-deps - 연결된 의존 서비스는 시작하지 않음
-t, --timeout - 종료 대기 시간을 초 단위로 지정
-w, --watch - 소스 변경을 감시하고 재빌드/갱신
--abort-on-container-exit - 컨테이너 하나가 종료되면 전체 중지
--abort-on-container-failure - 컨테이너가 실패하면 전체 중지

실행 예시

docker compose up -d
docker compose up -d --build
docker compose up --scale web=3

docker compose down

Compose가 만든 컨테이너와 네트워크를 중지하고 제거합니다.

Usage
docker compose down [OPTIONS] [SERVICES]

옵션

옵션기본값설명
--remove-orphans - Compose 파일에 정의되지 않은 서비스 컨테이너 제거
--rmi - 서비스 이미지 제거: local 또는 all
-t, --timeout - 종료 대기 시간(초)
-v, --volumes - Compose의 named volume 및 anonymous volume까지 제거

실행 예시

docker compose down
docker compose down -v
docker compose down --rmi all

docker compose ps

현재 Compose 프로젝트의 컨테이너 상태와 포트를 확인합니다.

Usage
docker compose ps [OPTIONS] [SERVICE...]

옵션

옵션기본값설명
-a, --all - 중지된 컨테이너까지 표시
--filter - 조건에 맞는 서비스만 표시
--format - table/json 또는 Go template 형식으로 출력
--no-trunc - 출력 내용을 줄이지 않고 모두 표시
--orphans true 프로젝트에 남아 있는 orphan 서비스 포함
-q, --quiet - 컨테이너 ID만 표시
--services - 서비스 이름만 표시
--status - 상태로 필터링: running / exited / paused 등

실행 예시

docker compose ps
docker compose ps -a
docker compose ps --status running
DOCKER COMPOSE COMMAND

docker compose logs

서비스 컨테이너의 로그를 조회합니다.

Usage
docker compose logs [OPTIONS] [SERVICE...]

옵션

옵션기본값설명
-f, --follow - 새 로그를 계속 실시간 출력
--index - 복제본이 여러 개일 때 특정 컨테이너 번호 지정
--no-color - 색상 없이 출력
--no-log-prefix - 서비스명 등의 로그 prefix 숨김
--since - 지정 시각 또는 상대시간 이후 로그만 표시
-n, --tail all 마지막 N줄만 표시
-t, --timestamps - 로그에 시간 표시
--until - 지정 시각 이전까지의 로그만 표시

실행 예시

docker compose logs
docker compose logs -f web
docker compose logs --tail 50 web

docker compose port

컨테이너 내부 포트가 호스트의 어느 공개 포트에 연결되었는지 확인합니다.

Usage
docker compose port [OPTIONS] SERVICE PRIVATE_PORT

옵션

옵션기본값설명
--dry-run - 실제 변경 없이 수행 내용을 확인하는 공통 옵션
--index - 서비스가 여러 replica일 때 특정 컨테이너 번호 선택
--protocol tcp tcp 또는 udp 선택

실행 예시

docker compose port web 80
docker compose port --protocol tcp web 80
docker compose port --index 2 web 80

docker compose build

Usage

옵션기본값설명

-q, --quiet - 빌드 출력 최소화
--sbom - SBOM 정보 추가
--ssh - 빌드 중 SSH 인증 사용
--with-dependencies - 의존 서비스도 함께 빌드

실행 예시

docker compose build
docker compose build --no-cache web
docker compose build --pull

docker compose exec

이미 실행 중인 서비스 컨테이너 안에서 명령을 실행합니다.

Usage
docker compose exec [OPTIONS] SERVICE COMMAND [ARGS...]

옵션기본값설명
-d, --detach - 명령을 백그라운드에서 실행

docker compose run

서비스 설정을 바탕으로 일회성 컨테이너를 만들어 명령을 실행합니다.

Usage
docker compose run [OPTIONS] SERVICE [COMMAND] [ARGS...]

옵션

옵션기본값설명
--build - 실행 전에 이미지 빌드
-d, --detach - 백그라운드 실행
--entrypoint - 이미지 ENTRYPOINT 재정의
-e, --env - 환경변수 지정
--env-from-file - 파일에서 환경변수 불러오기
--name - 일회성 컨테이너 이름 지정
--no-deps - 의존 서비스 시작 안 함
-p, --publish - 호스트에 포트 공개
--pull policy 이미지 pull 정책
--rm - 종료 후 컨테이너 자동 삭제
-P, --service-ports - 서비스에 정의된 포트를 그대로 공개
-u, --user - 실행 사용자 지정
-v, --volume - 볼륨 마운트
-w, --workdir - 작업 디렉터리 지정

실행 예시

docker compose run --rm web python manage.py migrate
docker compose run --rm app sh

docker compose config

Compose 파일을 해석하고 병합한 최종 설정을 출력하거나 검증합니다.

Usage
docker compose config [OPTIONS] [SERVICE...]

옵션

옵션기본값설명
--environment - 변수 치환에 사용되는 환경변수 출력
--format - 출력 형식: yaml 또는 json
--hash - 서비스 설정 hash 출력
--images - 이미지 이름만 출력
--models - model 이름 출력
--networks - network 이름 출력
--no-consistency - 설정 일관성 검사 생략
--no-env-resolution - 서비스 env_file 해석 안 함
--no-interpolate - 환경변수 치환 안 함
--no-normalize - Compose 모델 정규화 안 함
--no-path-resolution - 파일 경로 해석 안 함
-o, --output - 결과를 파일로 저장
--profiles - profile 이름 출력
-q, --quiet - 출력 없이 유효성만 검사
--services - 서비스 이름 출력
--variables - 모델 변수 및 기본값 출력
--volumes - volume 이름 출력

실행 예시

docker compose config
docker compose config -q
docker compose config --services

옵션기본값설명

docker compose publish
