# Codex 작업 지시서

## 목적

- 웹캠 얼굴을 MediaPipe로 추적한다.
- `a.png`를 양쪽 눈 위치에 실시간 합성한다.
- Windows 환경에서 실행 가능한 상태를 확인한다.

## 대상 파일

- 실행 코드: `eye_fire.py`
- 합성 이미지: `a.png`
- 패키지 목록: `requirements.txt`
- 사용 설명: `README.md`

## 작업 순서

1. 위 파일 4개가 같은 폴더에 있는지 확인한다.
2. Python 버전이 3.10~3.12인지 확인한다.
3. 가상환경을 만들고 활성화한다.
4. `pip install -r requirements.txt`를 실행한다.
5. `python eye_fire.py`를 실행한다.
6. 얼굴을 움직여 양쪽 눈의 합성 이미지가 따라오는지 확인한다.
7. Q 또는 ESC로 정상 종료되는지 확인한다.

## 오류 처리

- 먼저 오류 메시지와 재현 명령을 기록한다.
- 웹캠 오류면 카메라 권한, 다른 앱의 카메라 사용 여부, `--camera 1`을 확인한다.
- 이미지 오류면 파일명과 위치를 확인한다.
- 패키지 오류면 Python 버전과 가상환경 활성화 여부를 확인한다.
- 기존 파일 수정 전 내용을 확인하고, 필요한 파일만 최소 변경한다.
- 수정 후 구문 검사와 실행 절차를 다시 확인한다.

## 토큰·작업 효율 규칙

- 같은 파일을 반복해서 읽지 않는다.
- 오류 전체를 반복 출력하지 않고 핵심 원인과 마지막 관련 부분만 보고한다.
- 불필요한 신규 파일, 프레임워크, 기능을 추가하지 않는다.
- 완료 보고는 변경 파일, 검증 결과, 남은 문제만 짧게 작성한다.

## 완료 조건

- `python -m py_compile eye_fire.py`가 성공한다.
- 웹캠 창이 열리고 얼굴 1개를 추적한다.
- 불꽃 이미지가 양쪽 눈을 따라 이동·회전·확대/축소된다.
- Q와 ESC로 종료되고 웹캠 자원이 해제된다.
