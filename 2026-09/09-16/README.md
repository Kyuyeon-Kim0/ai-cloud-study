# 2026-09-16 (수) 학습 기록

## 학습 주제

- Flask 라우팅과 HTML 템플릿을 활용한 주문 화면 구성
- SQLite를 활용한 주문 데이터 저장 및 조회
- OpenAI API를 활용한 매출 요약과 운영 조언
- 주문·매출 데이터 대시보드와 관리자 기능 확장

## 핵심 이해

### 웹 애플리케이션과 데이터 저장

- Flask 라우트와 HTML 템플릿을 연결해 주문 흐름을 만들 수 있습니다.
- 주문 데이터를 SQLite에 저장하면 주문 내역과 매출을 조회·집계할 수 있습니다.

### AI 인사이트와 대시보드

- 집계한 주문·매출 데이터를 바탕으로 OpenAI API에 운영 조언 생성을 요청할 수 있습니다.
- 대시보드는 기간별 매출과 주문 현황을 한 화면에서 확인하도록 돕습니다.

## 실습 내용

- 피자 메뉴 조회, 주문 접수, 영수증 및 주문 내역 화면 만들기
- 주문 데이터를 SQLite에 저장하고 조회하기
- 매출 대시보드와 AI 인사이트 API 연결하기
- 관리자 작업 지시서를 바탕으로 관리 화면 확장하기
