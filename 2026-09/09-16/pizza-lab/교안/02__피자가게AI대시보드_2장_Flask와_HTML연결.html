WHY WEB SERVER

HTML 파일만으로는 가게를 못 엽니다

MISSION

웹서버가 왜 필요한지 이해하고, 파이썬에서 쓸 수 있는 웹 프레임워크와 서버의 종류를 구분한다.

WHY “Flask를 쓴다”에는 무엇으로 만들지(프레임워크)와 무엇으로 실행할지(서버) 두 선택이 숨어 있습니다.

HTML 파일만 있을 때 vs 웹서버가 있을 때

하고 싶은 일HTML 파일만웹서버(Flask)가 있으면
주문 저장브라우저를 닫으면 사라짐서버가 받아 DB에 저장 (3장)
여러 손님각자 자기 PC의 파일을 봄모두 같은 주소, 같은 데이터를 봄
금액 계산브라우저 계산 = 손님이 조작 가능서버가 다시 계산해서 확정
API 키 사용HTML에 넣으면 누구나 보기 가능키는 서버의 .env에만 있음 (4·5장)
AI 조언불가서버가 DB 집계 → OpenAI 호출 → 결과 전달

웹서버가 하는 일

① 요청 받기→② 주소 보고 할 일 고르기→③ 데이터 준비 (DB · AI)→④ HTML · JSON 만들기→⑤ 응답 보내기

식당의 홀 직원: 주문 받고 → 주방에 전달하고 → 접시에 담아 내보냅니다.

Flask 문법 한 장 요약08

이 장에서 쓰는 Flask 문법은 이게 전부입니다

문법어디에뜻
app = Flask(__name__)app.py웹 서버 만들기. app.py가 있는 폴더에서 templates · static을 찾음
@app.route("/order", methods=[…])app.py이 주소로 요청이 오면 바로 아래 함수 실행. methods가 없으면 GET만
render_template("x.html", 이름=값)app.py템플릿의 빈칸을 채워 HTML로 돌려줌
@app.route("/done/<int:order_id>")app.py주소 일부를 함수 인자로 받기
request.args · request.formapp.py주소 뒤 ?a=1 값 · 폼으로 보낸 값
redirect(url_for("done", order_id=7))app.py다른 주소로 이동시키기
{{ 변수 }}HTML값을 출력
{% for %} · {% if %} … {% end… %}HTML반복 · 조건. 반드시 닫는 줄이 있음
{% extends %} · {% block %} · |tojsonHTML공통 틀 물려받기 · 파이썬 값을 JS로
{{ url_for('함수이름') }}HTML주소를 함수 이름으로 만들기

두 가지 괄호만 구분하면 됩니다

{{ }} · 출력

“여기에 값을 찍어라”

{{ m.name }} → 페퍼로니
결과가 화면에 글자로 나타납니다.

{% %} · 명령

“이 구역을 이렇게 처리해라”

{% for m in menus %} … {% endfor %}
화면에는 안 보이고, 사이의 HTML을 반복·선택합니다.

왜 주소를 직접 쓰지 않고 url_for인가

주소를 글자로
href="/order"
나중에 주소를 /order-now로 바꾸면 HTML을 모두 찾아 고쳐야 합니다.
함수 이름으로
href="{{ url_for('order') }}"
@app.route만 고치면 링크가 자동으로 따라옵니다.

여기까지 한 일

  • 주소 → 함수 → 템플릿 순서로 화면의 출처를 찾았다
  • render_template이 데이터를 HTML 빈칸에 채우는 것을 확인했다
  • {% for %} · {% if %} · url_for · extends를 읽고 바꿔 봤다
  • 주소 값(request.args)과 폼 값(request.form)이 들어오는 길을 따라갔다
  • 꺼내기 → 검사 → 계산 → 저장 → 이동의 순서를 설명할 수 있다
