작업지시서의 7개 구역07
STEP 6-2 · WORK ORDER

AI가 추측할 틈을 없앤다

MISSION

작업지시서 템플릿의 7개 구역이 각각 무엇을 막는지 알고, 예시를 참고해 내 작업지시서 v1을 쓴다.

WHY AI의 실수 대부분은 빠진 정보를 그럴듯하게 채운 것입니다. 구역을 빠짐없이 채우면 실수가 줄고, 남은 실수는 완료 조건에서 걸립니다.

구역쓰는 것빠뜨리면 생기는 일
1. 목표누가 · 무엇을 · 왜화면의 초점이 흐려짐
2. 현재 프로젝트버전 · 폴더 · 쓸 수 있는 함수 · 테이블다른 버전 문법, 이미 있는 함수를 새로 만듦
3. 화면구역별 내용과 데이터 출처 (표)원하지 않는 지표 · 빠진 지표
4. 파일새로 만들 것 · 바꿀 것 · 주소app.py를 통째로 다시 씀 · 기존 기능 파손
5. 제한라이브러리 · 보안 · 수정 금지 범위엉뚱한 라이브러리, 비밀번호 하드코딩
6. 완료 조건시험할 수 있는 문장 (체크박스)“된 것 같다”로 끝남
7. 답의 형식전체 코드 / 추가분 · 설치 명령 · 확인 순서조각 코드만 와서 어디 붙일지 모름

같은 요구, 다른 문장

추측이 필요한 문장
“보안 신경 써줘”
“CPU 같은 거 보여줘”
“잘 되는지 확인”
무엇을 어떻게 막을지, 어떤 지표를, 무엇이 “잘 됨”인지 AI가 정합니다.
시험할 수 있는 문장
“ADMIN_PASSWORD가 비면 503”
“CPU · 메모리 · 디스크 %, 80·85·90 이상 빨강”
“페이지 20번 → 요청 수 증가”
받은 코드가 맞는지 누구나 같은 방법으로 확인할 수 있습니다.

# 작업지시서: 관리자 대시보드 (/admin) · v1 ## 1. 목표 가게 서버를 관리하는 사람이 **서버 · 앱 · DB 상태를 한 화면에서** 확인한다. 사장님 화면(/dashboard)과 분리하고, 비밀번호를 아는 사람만 볼 수 있게 한다. ## 2. 현재 프로젝트 - Python 3.12.10 / Flask 3.1.3 / SQLite(shop.db) / openai 3.14.0 / python-dotenv 1.2.3 - 폴더 구조 ``` pizza-lab/ ├─ app.py 라우트 모음. 맨 아래에 "6장 · 관리자 대시보드 자리" 주석이 있음 ├─ db.py get_conn() 과 DB_PATH(shop.db 경로)를 제공 ├─ ai.py has_key(), MODEL 을 제공. import 할 때 .env 를 읽음 ├─ templates/ base.html 을 {% extends %} 해서 사용 └─ static/style.css card, cards, panel, panels, ledger, table-wrap, hero 클래스가 있음 ``` - 공통 틀: templates/base.html 의 `{% block title %}`, `{% block content %}`, `{% block script %}`, `{% block main_class %}` - shop.db 의 orders 테이블: id, ordered_at('YYYY-MM-DD HH:MM:SS'), menu_id, size, crust, qty, amount, channel ## 3. 화면에 보여줄 것 | 구역 | 내용 | 데이터 출처 | |---|---|---| | 상단 | 마지막 확인 시각, 경고 요약(없으면 "이상 없음") | 서버 | | 서버 카드 4개 | CPU %, 메모리 %, 디스크 %(막대 포함), 서버 켜진 시간 · OS · Python 버전 | psutil, platform | | 앱 패널 | 최근 5분 요청 수, 5xx 수, 404 수, 평균 응답 ms, 가장 느린 주소, 앱 실행 시간, 앱 메모리 MB | before/after_request 로 메모리에 기록 | | DB · AI 패널 | shop.db 크기 KB, 전체 주문 수, 오늘 주문 수, 마지막 주문 시각, API 키 설정 여부, 모델 이름 | db.py, ai.py | | 최근 요청 표 | 최근 10건: 시각, 방식, 주소, 상태 코드, ms | 요청 기록 | - 경고 기준: CPU 80%, 메모리 85%, 디스크 90% 이상이면 빨간색 + 상단 경고 - 5초마다 JSON 으로 숫자만 새로 받아 화면 갱신 (페이지 새로고침 없이)
2구역이 하는 일

함수 이름(get_conn(), DB_PATH, has_key())과 템플릿 block 이름을 적어 두었기 때문에, AI가 새로 만들지 않고 있는 것을 재사용합니다. 테이블 칸 이름은 SQL 오타를 막습니다.
