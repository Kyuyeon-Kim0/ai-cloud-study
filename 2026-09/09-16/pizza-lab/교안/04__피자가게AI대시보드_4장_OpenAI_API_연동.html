WHY AI API

채팅창 대신 코드가 묻는다

토큰과 비용03

토큰 — AI가 글자를 세는 단위

AI는 글자를 토큰이라는 조각으로 나눠 읽고 씁니다. 영어는 단어 하나가 대략 1토큰, 한국어는 글자 하나가 1토큰 안팎으로 쪼개지는 경우가 많습니다. 요금은 보낸 토큰(입력)과 받은 토큰(출력)을 따로 셉니다.

INPUT
보낸 글
지시문 + 질문 + 자료
OUTPUT
받은 글
보통 입력보다 비쌈
REASONING
생각 토큰
추론하는 모델은 보이지 않는 생각도 출력으로 계산
USAGE
응답에 기록
response.usage 로 확인 (미션 4-13)

모델별 가격 (100만 토큰당, 달러)

모델입력출력성격

호출 템플릿 ask()04
STEP 4-1 · TEMPLATE

질문 하나를 보내는 여섯 줄

MISSION

ai.py의 ask()가 키를 찾고, 요청을 만들고, 답 글자만 꺼내는 과정을 설명한다.

WHY 이 과정의 AI 호출은 전부 ask() 하나를 거칩니다.

ai.py · 앞부분완성본
import os from pathlib import Path from dotenv import load_dotenv from openai import (APIConnectionError, APIStatusError, AuthenticationError, NotFoundError, OpenAI, PermissionDeniedError, RateLimitError) load_dotenv(Path(__file__).parent / ".env") # .env → 환경변수 MODEL = os.getenv("OPENAI_MODEL") or "gpt-5.6-luna"
ai.py · ask()완성본
def ask(question, system=SYSTEM_PROMPT): """AI에게 묻고 답 글자를 돌려준다 — 이 과정의 호출 템플릿""" client = OpenAI() # OPENAI_API_KEY 를 환경변수에서 읽음 response = client.responses.create( model=MODEL, instructions=system, # 역할 지시 input=question, # 질문 ) return response.output_text # 답 글자만 꺼내기
load_dotenv(…).env → 환경변수
ai.py 옆의 .env를 읽어 OPENAI_API_KEY, OPENAI_MODEL을 환경변수로 올립니다. 파일을 불러오는 순간 한 번 실행됩니다.
OpenAI()클라이언트
인자 없이 만들면 환경변수의 키를 자동으로 씁니다. 코드에 sk-…가 등장하지 않는 이유입니다.
.output_text답 글자만
응답에는 번호 · 모델 · 사용량 등이 함께 오지만, 화면에 필요한 글자만 꺼냅니다.

돌아오는 응답 (줄임)JSON

응답의 숫자는 예시입니다. response.output_text는 output 안에 흩어진 글자를 한 줄로 모아 주는 편의 기능입니다.

" "살릴 아이디어 2개만.") print(ask(question)) # ③ 역할 지시를 바꿔서 묻기 print("\n[3] 말투 바꾸기") print(ask("오늘 비가 와. 배달 손님을 늘릴 방법 하나.", system="너는 사투리를 쓰는 유쾌한 피자집 매니저다."))
