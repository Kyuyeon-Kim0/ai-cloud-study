## 학습 주제

- Python으로 프로세스의 CPU·메모리 사용량 측정
- 파일명과 로그에서 필요한 값 추출
- 함수, 클래스, `with` 문을 이용한 측정 도구 구성
- Pillow와 OpenCV의 이미지 읽기 성능 비교
- 웹캠 실행 중 시스템 자원을 기록하고 결과 해석

## 핵심 이해

### 시스템 자원 측정

- `psutil`로 현재 프로세스의 메모리 사용량과 CPU 사용량을 확인한다.
- 작업 전후의 값과 소요 시간을 비교하면 작업의 자원 사용량을 측정할 수 있다.
- 측정값은 딕셔너리로 만들고 CSV에 누적해 여러 실행 결과를 비교한다.
- 반복 측정에서는 첫 실행 결과와 평균·중앙값의 차이를 고려한다.

### 파일·이미지 처리

- `os`와 `pathlib`를 사용해 환경에 맞는 파일 경로를 다룬다.
- 정규표현식으로 파일명과 로그에서 해상도, 날짜, 숫자 등의 값을 추출한다.
- 같은 이미지를 Pillow와 OpenCV로 읽어 메모리 증가량과 처리 시간을 비교한다.
- 웹캠처럼 반드시 닫아야 하는 대상은 클래스와 `with` 문으로 안전하게 관리한다.
