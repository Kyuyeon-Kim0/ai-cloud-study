내 집에서 구글까지
인터넷은 어떻게 연결될까?

주소창에 google.com을 입력한 뒤 화면이 뜨기까지의 길을 아주 쉽게 따라가 봅니다.

한 줄 요약: 내 PC → Wi‑Fi → 공유기 → 통신사 → 인터넷 → 구글 서버 순서로 데이터가 이동합니다.

1. 전체 네트워크 구성

내 컴퓨터

웹 브라우저에서 google.com을 입력합니다.

→
📶

공유기

집 안 기기들을 인터넷으로 연결하는 출입구입니다.

→

KT, SK브로드밴드, LG U+ 같은 인터넷 사업자입니다.

🌐

인터넷

전 세계 수많은 네트워크가 서로 연결된 거대한 통신망입니다.

→
🧭

DNS

google.com이라는 이름을 실제 IP 주소로 바꿔 줍니다.

→
🗄️

구글 서버

요청을 받고 검색 화면과 데이터를 다시 보내 줍니다.

2. 실제로 무슨 일이 일어날까?

1

주소 입력

브라우저에 google.com을 입력합니다.

2

DNS 조회

컴퓨터는 “google.com의 실제 IP가 뭐지?”라고 DNS 서버에 물어봅니다.

3

공유기로 전달

내 PC의 요청이 Wi‑Fi를 통해 공유기로 이동합니다.

4

통신사로 이동

공유기는 데이터를 집 밖의 통신사 네트워크로 보냅니다.

5

구글 서버 도착

인터넷의 여러 장비를 거쳐 구글 서버에 요청이 도착합니다.

6

화면 응답

구글 서버가 HTML, 이미지, 데이터 등을 다시 보내고 브라우저가 화면을 그립니다.

3. 집 안에서 쓰는 IP와 인터넷에서 보이는 IP

구분예시쉽게 말하면
사설 IP192.168.0.15우리 집 안에서 쓰는 방 번호
게이트웨이192.168.0.1건물 밖으로 나가는 정문
공인 IP통신사가 할당인터넷 세상에서 우리 집을 구분하는 주소
DNS8.8.8.8 등google.com 같은 이름을 IP 주소로 찾아주는 전화번호부
비유: 내 컴퓨터는 아파트의 한 세대, 공유기는 아파트 정문, 통신사는 큰 도로, 인터넷은 전국 도로망, 구글 서버는 목적지 건물이라고 생각하면 쉽습니다.

5. "Wi‑Fi 연결됨"인데 인터넷이 안 되는 이유

문제 위치무슨 뜻?먼저 확인할 것
내 PCIP를 못 받았거나 어댑터 문제ipconfig
공유기게이트웨이까지 못 감ping 192.168.0.1
외부 인터넷통신사 또는 회선 문제 가능ping 8.8.8.8
DNSIP는 되지만 이름 변환 실패ping google.com
특정 사이트상대 서버 문제 가능다른 사이트와 비교
주의: ping이 실패했다고 무조건 인터넷 고장은 아닙니다. 보안 정책에 따라 ICMP(ping)를 차단하는 서버도 있습니다.

6. 이것만 기억하세요

Wi‑Fi는 내 PC와 공유기를 연결하는 방법입니다.

공유기는 집 안 네트워크와 인터넷을 연결하는 출입구입니다.

IP는 컴퓨터가 서로를 찾는 주소입니다.

DNS는 사람에게 쉬운 이름을 IP 주소로 바꿔 줍니다.

인터넷은 전 세계 수많은 네트워크가 연결된 거대한 통신망입니다.
