# 2026-10-29 (목) 학습 기록

## 학습 주제

- Transformer 언어 모델의 구성 요소와 어텐션
- BERT·GPT 구조 비교 및 RAG 모델 선택
- Hugging Face 모델·토크나이저·데이터셋 활용
- LLMOps 방식의 FAQ 챗봇 구성과 평가 흐름

## 핵심 이해

### Transformer와 언어 모델

- 토큰 ID, 패딩 마스크, 임베딩, 위치 정보, QKV 어텐션, 인과 마스크, FFN·정규화, LM 헤드의 역할을 코드로 확인함.
- BERT의 양방향 문맥 표현과 GPT의 다음 토큰 생성 방식 차이를 비교함.
- 토크나이저 결과와 마스크를 통해 모델 입력이 구성되는 과정을 이해함.

### Hugging Face와 RAG

- 모델 태스크와 설정, 파이프라인, 토크나이저, 데이터셋, 모델 저장·불러오기를 실습함.
- 임베딩 유사도 검색과 생성 모델을 연결한 간단한 RAG 흐름을 구성함.
- 모델 선택 시 데이터와 태스크, 실행 환경, 평가 결과를 함께 고려해야 함을 확인함.

### LLMOps FAQ 챗봇

- FAQ와 동의어 데이터를 수정하고 평가 결과를 확인하는 실습 파이프라인을 구성함.
- 파일 변경 감지에 따른 재실행 흐름과 모델 버전 전환·기록 구조를 살펴봄.
- API 키가 없을 때 프로젝트의 모의 응답 흐름으로 실행할 수 있음을 확인함.

## 실습 내용

- Transformer 구성 요소별 동작을 작은 Python 예제로 확인함.
- BERT와 GPT의 토크나이저 및 생성 방식을 비교하고, 미니 RAG와 모델 비교를 실습함.
- Hugging Face 파이프라인, 임베딩 검색, 데이터셋, 모델 저장·재로드를 실습함.
- FAQ 챗봇의 학습·평가·버전 관리 흐름과 파일 감시 실행을 살펴봄.
