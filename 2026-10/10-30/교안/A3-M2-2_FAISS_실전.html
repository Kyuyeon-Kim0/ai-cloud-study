01-3. Hugging Face 파이프라인 출력 들여다보기

파이프라인은 문장 벡터가 아니라 토큰마다 384차원 벡터를 돌려줍니다.

01_데이터와_임베딩.ipynb · 01-3
import numpy as np
import faiss
from transformers import pipeline
from emb import EMB_MODEL

fe = pipeline("feature-extraction", model=EMB_MODEL, device=-1)
s = "query: 택배 언제 와요?"
out = fe(s)
arr = np.array(out)
print("모델:", EMB_MODEL)
print("출력 모양:", arr.shape, "← 문장 1개 × 토큰 수 × 384")
print("토큰:", fe.tokenizer.tokenize(s))
v = arr[0].mean(axis=0)
print("토큰 평균:", v.shape, "길이", round(float(np.linalg.norm(v)), 3))

한 줄씩 읽기

코드문법과 뜻
pipeline("feature-extraction", model=EMB_MODEL, device=-1)모델의 마지막 층 출력을 그대로 주는 파이프라인. 처음 실행할 때 모델(약 470MB)을 내려받습니다. device=-1은 CPU.
"query: 택배 언제 와요?"e5 모델 규칙: 질문 앞에 query: , 문서 앞에 passage: .
np.array(out).shape(1, 토큰 수, 384). 1은 문장 개수.
fe.tokenizer.tokenize(s)파이프라인 안의 토크나이저로 토큰 조각 보기. 앞뒤 특수 토큰 2개가 더해져 출력 모양의 토큰 수가 됩니다.
arr[0].mean(axis=0)토큰 축 평균 → (384,). 문장 하나 = 벡터 하나.

01-4. embed() 함수 만들고 FAQ 20건을 벡터로

01_데이터와_임베딩.ipynb · 01-4
def embed(texts, kind="passage"):
    outs = fe([f"{kind}: {t}" for t in texts])                       # 문장마다 [1][토큰][384]
    X = np.array([np.array(o[0]).mean(axis=0) for o in outs], dtype="float32")
    faiss.normalize_L2(X)                                              # 길이 1 → 내적 = 코사인
    return X

X = embed(faq["doc"].tolist())
print("X:", X.shape, X.dtype)
print("길이:", np.linalg.norm(X, axis=1).round(3)[:5], "...")
np.save("faq_vectors.npy", X)
print("저장: faq_vectors.npy")

한 줄씩 읽기

코드문법과 뜻
def embed(texts, kind="passage")문장 목록을 받아 (개수, 384) 배열을 돌려주는 함수. 기본은 문서용 passage.
fe([f"{kind}: {t}" for t in texts])리스트를 넣으면 문장마다 [1][토큰][384] 결과가 리스트로 나옵니다.
np.array(o[0]).mean(axis=0)문장마다 토큰 평균. 문장을 하나씩 처리하므로 PAD가 섞이지 않습니다.
dtype="float32"FAISS는 float32만 받습니다.
faiss.normalize_L2(X)행마다 길이 1로(제자리 수정). 이후 내적 = 코사인.
np.save("faq_vectors.npy", X)벡터를 파일로. 다음 노트북에서 np.load로 읽습니다.

def search(question, k=3, categories=None):
    params = None
    if categories:
        params = faiss.SearchParameters(sel=faiss.IDSelectorBatch(ids_of(categories)))
    D, I = index.search(embed([question], kind="query"), k, params=params)
    hits = [(int(i), float(d)) for d, i in zip(D[0], I[0]) if i != -1]
    res = meta.loc[[i for i, _ in hits], ["category", "question", "answer"]].copy()
    res.insert(0, "score", [round(s, 3) for _, s in hits])
    return res

def ids_of(categories):
    return meta.index[meta["category"].isin(categories)].to_numpy(dtype="int64")

def search(question, k=3, categories=None):
    params = None
    if categories:
        params = faiss.SearchParameters(sel=faiss.IDSelectorBatch(ids_of(categories)))
    D, I = index.search(embed([question], kind="query"), k, params=params)
    hits = [(int(i), float(d)) for d, i in zip(D[0], I[0]) if i != -1]
    res = meta.loc[[i for i, _ in hits], ["category", "question", "answer"]].copy()
    res.insert(0, "score", [round(s, 3) for _, s in hits])
    return res

07. 리랭킹 — 후보를 뽑고, 다시 줄 세우기

임베딩 검색은 질문과 문서를 따로 벡터로 만들어 비교합니다. 리랭커(cross-encoder)는 질문과 문서를 한 쌍으로 모델에 넣어 관련도를 직접 계산합니다. 보통 더 정확하지만 문서마다 모델을 돌려야 해서 느리므로, FAISS로 후보 몇 개를 뽑은 뒤 그 후보만 다시 줄 세웁니다.

def evaluate(fn, **kw):
    rows = []
    for q, gold in tests.itertuples(index=False):
        ranked = fn(q, **kw).index.tolist()
        rows.append({"question": q, "gold": gold, "top1": ranked[0],

def search(question, k=3, categories=None):
    params = None
    if categories:
        params = faiss.SearchParameters(sel=faiss.IDSelectorBatch(ids_of(categories)))

    res = meta.loc[[i for i, _ in hits], ["category", "question", "answer"]].copy()
    res.insert(0, "score", [round(s, 3) for _, s in hits])
    return res
