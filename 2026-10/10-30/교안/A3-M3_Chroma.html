00. Chroma 한눈에 — FAISS에서 직접 만들던 것을 DB가 해 준다

A3-M2-2에서는 FAISS에 벡터와 번호만 넣고, 원문·카테고리는 pandas 표로 따로 들고 다니며, 필터는 허용 id 목록으로 만들고, 저장은 파일 세 개로 했습니다. Chroma는 이것을 컬렉션 하나가 모두 맡습니다. 같은 FAQ CSV, 같은 e5 벡터, 같은 평가 질문으로 해 보며 차이를 봅니다.

기능문법한 줄 설명

01-6. 결과를 표로 돌려주는 search() 함수

매번 [0]을 붙이는 게 번거로우므로 결과를 표로 돌려주는 함수를 만듭니다. 이후 노트북에서 계속 씁니다.

01_Chroma_저장과_검색.ipynb · 01-6
def search(question, k=3, where=None):
    r = col.query(query_embeddings=embed([question], kind="query"), n_results=k, where=where)
    return pd.DataFrame({
        "faq_id": [int(i) for i in r["ids"][0]],
        "score": [round(1 - d, 3) for d in r["distances"][0]],
        "category": [m["category"] for m in r["metadatas"][0]],
        "question": [m["question"] for m in r["metadatas"][0]],
    })

print(search("환불 며칠 걸려요?").to_string(index=False))

02. 메타데이터 필터 — where 한 줄로

A3-M2-2에서는 카테고리 → 허용 id 목록 → IDSelectorBatch → SearchParameters 네 단계였습니다. Chroma는 where 딕셔너리 하나입니다.

조건where 쓰는 법
같다{"category": "환불"} 또는 {"category": {"$eq": "환불"}}
다르다{"category": {"$ne": "회원"}}
목록 안{"category": {"$in": ["환불", "결제"]}}
목록 밖{"category": {"$nin": [...]}}
숫자 비교{"price": {"$gte": 10000}} ($gt $gte $lt $lte)
여러 조건{"$and": [조건1, 조건2]}, {"$or": [...]}
원문 조건where_document={"$contains": "마이페이지"}

02-1. 준비 — 저장된 컬렉션 다시 열기

02 노트북의 준비 셀. 01에서 만든 컬렉션을 다시 엽니다.

02_메타데이터_필터와_수정.ipynb · 02-1
import pandas as pd
import chromadb
from emb import embed

client = chromadb.PersistentClient(path="chroma_db")
col = client.get_collection("shop_faq")                     # 01에서 만든 컬렉션 다시 열기
print("저장된 개수:", col.count())

def search(question, k=3, where=None, where_document=None):
    r = col.query(query_embeddings=embed([question], kind="query"), n_results=k,
                  where=where, where_document=where_document)
    return pd.DataFrame({
        "faq_id": [int(i) for i in r["ids"][0]],
        "score": [round(1 - d, 3) for d in r["distances"][0]],
        "category": [m["category"] for m in r["metadatas"][0]],
        "question": [m["question"] for m in r["metadatas"][0]],
    })

04. RAG 평가 — Chroma 검색도 같은 방법으로 잰다

A3-M2-2와 같은 평가 질문 12개, 같은 지표(Hit@1·Hit@3·MRR)로 잽니다. 평가 함수 evaluate()는 검색 함수를 인자로 받아서, 다음 탭의 리랭킹도 같은 함수로 잽니다.

지표뜻
Hit@1정답 FAQ가 1위인 질문 비율
Hit@3정답이 3위 안인 질문 비율
MRR1/정답 순위의 평균 (1위 1, 2위 0.5, 3위 0.33, 못 찾으면 0)

04-1. 준비 — 컬렉션 열고 search · evaluate 만들기

03 노트북의 준비 셀. search·evaluate·summary를 만듭니다.

03_RAG평가와_리랭킹.ipynb · 04-1
import time
import numpy as np
import pandas as pd
import chromadb
from emb import embed, RERANK_MODEL

client = chromadb.PersistentClient(path="chroma_db")
col = client.get_collection("shop_faq")
tests = pd.read_csv("shop_faq_tests.csv")

def search(question, k=3, where=None):
    r = col.query(query_embeddings=embed([question], kind="query"), n_results=k, where=where)
    return pd.DataFrame({
        "faq_id": [int(i) for i in r["ids"][0]],
        "score": [round(1 - d, 3) for d in r["distances"][0]],
        "category": [m["category"] for m in r["metadatas"][0]],
        "question": [m["question"] for m in r["metadatas"][0]],
        "doc": r["documents"][0],
    })

def evaluate(fn, **kw):
    rows = []
    for q, gold in tests.itertuples(index=False):
        ranked = fn(q, **kw)["faq_id"].tolist()
        rows.append({"question": q, "gold": gold, "top1": ranked[0],
                     "rank": ranked.index(gold) + 1 if gold in ranked else np.nan})
    return pd.DataFrame(rows)

def summary(ev):
    return {"Hit@1": round(float((ev["rank"] == 1).mean()), 3), "Hit@3": round(float((ev["rank"] <= 3).mean()), 3),
            "MRR": round(float((1 / ev["rank"]).fillna(0).mean()), 3)}

print("FAQ", col.count(), "건 | 평가 질문", len(tests), "개")

한 줄씩 읽기

코드문법과 뜻
"doc": r["documents"][0]리랭킹에 원문이 필요해서 결과 표에 원문 열을 추가했습니다.
def evaluate(fn, **kw)검색 함수 fn으로 평가 질문을 모두 돌려 순위 표를 만듭니다. **kw는 k·pool 같은 인자를 그대로 넘깁니다.
ranked.index(gold) + 1 if gold in ranked else np.nan정답의 순위. 5위 안에 없으면 NaN.
(1 / ev["rank"]).fillna(0).mean()MRR. 못 찾은 질문은 0점.

05. 리랭킹 — Chroma 후보를 다시 줄 세우기

Chroma로 후보 몇 개를 뽑고, 리랭커(cross-encoder)가 (질문, 문서) 쌍마다 점수를 매겨 다시 정렬합니다. 리랭커는 A3-M2-2와 같은 모델입니다.

질문비번 까먹었어요
→
Chroma후보 pool개
→
리랭커쌍마다 점수
→
정렬상위 k개

05-1. 리랭커 붙이기

03_RAG평가와_리랭킹.ipynb · 05-1
from transformers import pipeline
rr = pipeline("text-classification", model=RERANK_MODEL, device=-1)

def search_rerank(question, k=3, pool=8, where=None):
    cand = search(question, k=pool, where=where)
    pairs = [{"text": question, "text_pair": d} for d in cand["doc"]]
    cand["rerank"] = [round(s["score"], 3) for s in rr(pairs, function_to_apply="none")]
    return cand.sort_values("rerank", ascending=False).head(k)

q = "비번 까먹었어요"
print("[Chroma 순서]")
print(search(q, k=5)[["faq_id", "score", "question"]].to_string(index=False))
print("\n[리랭킹 순서]")
print(search_rerank(q, k=5, pool=5)[["faq_id", "score", "rerank", "question"]].to_string(index=False))

한 줄씩 읽기

코드문법과 뜻
pipeline("text-classification", model=RERANK_MODEL)리랭커 불러오기. 처음 한 번 내려받습니다.
{"text": question, "text_pair": d}질문과 원문을 한 쌍으로.
function_to_apply="none"점수를 변환하지 않은 원래 값. 순서만 쓰므로 그대로 둡니다.
sort_values("rerank", ascending=False).head(k)리랭커 점수 내림차순 상위 k개.

04_실습과제.ipynb · x0
import time
import numpy as np
import pandas as pd
import chromadb
from emb import embed, RERANK_MODEL

client = chromadb.PersistentClient(path="chroma_db")
col = client.get_collection("shop_faq")
tests = pd.read_csv("shop_faq_tests.csv")

def search(question, k=3, where=None):
    r = col.query(query_embeddings=embed([question], kind="query"), n_results=k, where=where)
    return pd.DataFrame({
        "faq_id": [int(i) for i in r["ids"][0]],
        "score": [round(1 - d, 3) for d in r["distances"][0]],
        "category": [m["category"] for m in r["metadatas"][0]],
        "question": [m["question"] for m in r["metadatas"][0]],
        "doc": r["documents"][0],
    })

def evaluate(fn, **kw):
    rows = []
    for q, gold in tests.itertuples(index=False):
        ranked = fn(q, **kw)["faq_id"].tolist()
        rows.append({"question": q, "gold": gold, "top1": ranked[0],
                     "rank": ranked.index(gold) + 1 if gold in ranked else np.nan})
    return pd.DataFrame(rows)

def summary(ev):
    return {"Hit@1": round(float((ev["rank"] == 1).mean()), 3), "Hit@3": round(float((ev["rank"] <= 3).mean()), 3),
            "MRR": round(float((1 / ev["rank"]).fillna(0).mean()), 3)}

print("FAQ", col.count(), "건 | 평가 질문", len(tests), "개")
from transformers import pipeline
rr = pipeline("text-classification", model=RERANK_MODEL, device=-1)

def search_rerank(question, k=3, pool=8, where=None):
    cand = search(question, k=pool, where=where)
    pairs = [{"text": question, "text_pair": d} for d in cand["doc"]]
    cand["rerank"] = [round(s["score"], 3) for s in rr(pairs, function_to_apply="none")]
    return cand.sort_values("rerank", ascending=False).head(k)

06-2. 과제 1 · 카테고리 필터로 평가하기

def search_cat(q, gold, k=5):
    cat = col.get(ids=[str(gold)])["metadatas"][0]["category"]
    return search(q, k=k, where={"category": cat})

rows = []
for q, gold in tests.itertuples(index=False):
    ranked = search_cat(q, gold)["faq_id"].tolist()
    rows.append({"question": q, "gold": gold, "top1": ranked[0], "rank": ranked.index(gold) + 1 if gold in ranked else np.nan})
print(pd.DataFrame({"필터 없음": summary(evaluate(search, k=5)), "정답 카테고리 필터": summary(pd.DataFrame(rows))}).to_string())
