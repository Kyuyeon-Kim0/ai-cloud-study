00. 왜 토크나이저부터 보나

검색·RAG·LLM 비용은 모두 ‘문장을 어떤 조각으로 나누었는가’에서 출발합니다. 이 모듈은 Hugging Face 토크나이저와 OpenAI tiktoken을 손에 익히고, 그 조각으로 유사도를 계산해 검색 품질이 어떻게 달라지는지 직접 확인합니다.

이 모듈에서 할 일

같은 문장을 여러 방식으로 잘라 보고(글자·띄어쓰기·형태소·서브워드), Hugging Face tokenizers로 우리 데이터 전용 토크나이저를 직접 학습한 뒤, transformers의 토크나이저 문법과 OpenAI의 tiktoken 문법을 익힙니다. 마지막으로 토크나이저만 바꿔 쇼핑몰 FAQ 검색 정확도가 어떻게 바뀌는지 숫자로 비교하고, 임베딩 모델로 계산한 유사도와 견줘 봅니다.

01. 토큰이란 — 같은 문장을 다섯 가지로 잘라 보기

토큰은 ‘모델이나 검색엔진이 한 단위로 다루는 조각’입니다. 무엇을 한 조각으로 볼지 정하는 규칙이 토크나이저입니다. 규칙마다 장단점이 분명해서, 어떤 규칙을 고르느냐가 곧 검색·생성 품질의 바탕이 됩니다.

이 단계의 의미

RAG에서 문서를 검색할 때 ‘질문의 조각’과 ‘문서의 조각’이 겹쳐야 키워드 점수가 생기고, 임베딩 모델도 결국 토큰 단위로 문장을 읽습니다. 그래서 문장이 어떻게 잘리는지 눈으로 보는 습관이 첫 단계입니다.

import re
kiwi = Kiwi()
enc = tiktoken.get_encoding("o200k_base")

ways = {
    "글자":      list(sentence.replace(" ", "")),
    "띄어쓰기":  sentence.split(),
    "정규식 단어": re.findall(r"\w+|[^\w\s]", sentence),
    "형태소(kiwi)": [t.form for t in kiwi.tokenize(sentence)],
    "BPE(tiktoken o200k)": [enc.decode([i]) for i in enc.encode(sentence)],
}
for name, toks in ways.items():
    print(f"{name:<18} {len(toks):>2}개  {toks}")

01-3. 다섯 방식 비교

방식어떻게 자르나장점약점주로 쓰는 곳
글자한 글자씩모르는 단어가 없음조각에 뜻이 거의 없고 너무 많음글자 n-gram 검색
띄어쓰기공백 기준가장 단순하고 빠름한국어는 조사가 붙어 ‘냉장고는’ ‘냉장고도’가 다른 조각영어 기본 검색
정규식 단어글자 묶음과 기호 분리괄호·물음표가 떨어짐조사 문제는 그대로전처리 보조
형태소(kiwi)뜻을 가진 최소 단위 + 품사‘냉장고’와 ‘는’이 분리. 품사로 골라 쓸 수 있음사전에 없는 신조어·모델명은 잘게 쪼개짐한국어 키워드 검색·BM25
서브워드(BPE·WordPiece)자주 나오는 글자 묶음을 학습어휘 수를 고정하면서 모르는 단어도 조각으로 표현사람이 보기엔 경계가 어색함모든 신경망 모델(BERT·GPT·e5)
tiktoken 결과의 ‘�’는 오류가 아닙니다

BPE(tiktoken)는 글자가 아니라 UTF-8 바이트를 묶습니다. 한글 한 글자는 3바이트라서, ‘냉’이 두 토큰에 걸쳐 나뉘면 토큰 하나만 따로 decode할 때 반쪽짜리 바이트가 되어 ‘�’로 보입니다. 두 토큰을 함께 decode하면 ‘냉’으로 정상 복원됩니다. 10번 탭에서 바이트를 직접 확인합니다.

from kiwipiepy.utils import Stopwords

KEEP = {"NNG", "NNP", "NNB", "SL", "SN", "VV", "VA", "XR"}      # 일반·고유·의존명사, 외국어, 숫자, 동사, 형용사, 어근
def kiwi_tokens(text, keep=KEEP):
    return [t.form for t in kiwi.tokenize(text) if t.tag in keep]

q = "냉장고는 언제쯤 오나요?"
print("전체      :", [(t.form, t.tag) for t in kiwi.tokenize(q)])
print("품사 골라냄:", kiwi_tokens(q))
print("불용어 제거:", [t.form for t in kiwi.tokenize(q, stopwords=Stopwords())])

03. 서브워드 — BPE가 어휘를 만드는 과정 따라가기

BERT·GPT·e5 같은 모델은 형태소 분석기를 쓰지 않습니다. 대신 말뭉치에서 ‘자주 붙어 나오는 조각’을 통계로 찾아 어휘를 만듭니다. 그 대표 방법인 BPE(Byte Pair Encoding)의 병합 과정을 손으로 따라갑니다.

왜 서브워드인가

단어 단위 어휘는 끝이 없습니다(신조어, 모델명, 오타). 글자 단위는 조각에 뜻이 없습니다. 서브워드는 그 중간입니다. 자주 나오는 ‘배송’은 한 조각, 드문 ‘배송지’는 ‘배송’+‘지’처럼 나눠서, 정해진 어휘 수(예: 3만 개) 안에서 어떤 문장이든 표현합니다.

03-1. BPE 병합을 손으로 따라가기

01_토큰_나누기_기초.ipynb · 03-1
from collections import Counter

words = {"배송": 6, "배송비": 4, "배송지": 3, "배달": 2, "배달비": 2}     # 단어: 등장 횟수
splits = {w: list(w) for w in words}                                      # 처음엔 글자 단위
vocab = sorted({ch for w in words for ch in w})
print("시작 어휘:", vocab)

for step in range(1, 5):
    pairs = Counter()
    for w, freq in words.items():                                         # 이웃한 두 조각 쌍 세기
        s = splits[w]
        for a, b in zip(s, s[1:]):
            pairs[(a, b)] += freq
    (a, b), cnt = pairs.most_common(1)[0]                                 # 가장 많이 나온 쌍
    for w in words:                                                       # 그 쌍을 하나로 합친다
        s, out, i = splits[w], [], 0
        while i < len(s):
            if i < len(s) - 1 and s[i] == a and s[i + 1] == b:
                out.append(a + b); i += 2
            else:
                out.append(s[i]); i += 1
        splits[w] = out
    vocab.append(a + b)
    print(f"병합 {step}: '{a}'+'{b}' (함께 {cnt}번) → {splits}")
print("최종 어휘:", vocab)

Q. 모델과 다른 토크나이저를 써도 되나요?

def truncate_tokens(text, max_tokens, enc=o200k):
    ids = enc.encode(text)
    return enc.decode(ids[:max_tokens]), len(ids)

def chunk_tokens(text, size=20, overlap=5, enc=o200k):
    ids = enc.encode(text)
    step = size - overlap
    return [enc.decode(ids[i:i + size]) for i in range(0, max(len(ids) - overlap, 1), step)]

from collections import Counter
a, b = "택배 언제 와요", "배송은 언제 오나요"
for name in ["띄어쓰기", "kiwi 형태소", "글자 2-gram"]:
    ta, tb = Counter(TOKENIZERS[name](a)), Counter(TOKENIZERS[name](b))
    vocab = sorted(set(ta) | set(tb))
    va = np.array([ta[w] for w in vocab]); vb = np.array([tb[w] for w in vocab])
    cos = va @ vb / (np.linalg.norm(va) * np.linalg.norm(vb))
    jac = len(set(ta) & set(tb)) / len(set(ta) | set(tb))
    print(f"[{name}] 어휘 {vocab}")
    print(f"   A {va.tolist()}  B {vb.tolist()}  → 코사인 {cos:.3f}  자카드 {jac:.3f}")

def evaluate(name, k=3):

    h1 = h3 = 0

import torch, torch.nn.functional as F
from transformers import AutoTokenizer, AutoModel
from shop_faq import FAQ, TESTS

name = "intfloat/multilingual-e5-small"
tok = AutoTokenizer.from_pretrained(name)
model = AutoModel.from_pretrained(name).eval()

@torch.inference_mode()
def e5(texts, kind):
    b = tok([f"{kind}: {t}" for t in texts], padding=True, truncation=True, max_length=256, return_tensors="pt")
    h = model(**b).last_hidden_state
    m = b["attention_mask"].unsqueeze(-1).float()
    return F.normalize((h * m).sum(1) / m.sum(1), dim=1)

D = e5([f"{q} {a}" for _, _, q, a in FAQ], "passage")
print("문서 벡터:", tuple(D.shape))
ids = [i for i, *_ in FAQ]
hit1 = 0
for q, gold in TESTS:
    s = D @ e5([q], "query")[0]
    top = s.argsort(descending=True)[:3].tolist()
    hit1 += ids[top[0]] == gold
    print(f"{q:<24} → {[ids[i] for i in top]}  {[round(float(s[i]), 3) for i in top]}")
print("e5 Hit@1 =", hit1, "/", len(TESTS))

BASE = {"NNG", "NNP", "NNB", "SL", "SN", "VV", "VA", "XR"}
def hit1(keep):
    f = lambda s: [t.form for t in kiwi.tokenize(s) if t.tag in keep]
    vec = TfidfVectorizer(tokenizer=f, lowercase=False, token_pattern=None)
    X = vec.fit_transform(docs)
    return sum(ids[(X @ vec.transform([q]).T).toarray().ravel().argmax()] == g for q, g in TESTS)

KEEP = {"NNG", "NNP", "NNB", "SL", "SN", "VV", "VA", "XR"}
fk = lambda s: [t.form for t in kiwi.tokenize(s) if t.tag in KEEP]
fc = lambda s: [s[i:i+2] for i in range(len(s) - 1) if " " not in s[i:i+2]]
vk = TfidfVectorizer(tokenizer=fk, lowercase=False, token_pattern=None); Xk = vk.fit_transform(docs)

hit = 0
for q, g in TESTS:
    s = 0.5 * (Xk @ vk.transform([q]).T).toarray().ravel() + 0.5 * (Xc @ vc.transform([q]).T).toarray().ravel()

print("섞은 점수 Hit@1:", hit, "/ 12")

16-1. 꼭 기억할 다섯 가지

  1. 모델에는 그 모델의 토크나이저만 쓴다. 토크나이저가 다르면 번호의 뜻이 다르다.
  2. 길이 한도는 토큰 수다. truncation은 근거를 조용히 버리니, 긴 문서는 문장 경계 + 토큰 한도로 나눈다.
  3. 한국어는 토큰이 많이 나온다. 비용과 한도는 tiktoken으로 미리 센다. 최신 인코딩(o200k)이 한국어에 유리하다.
  4. 키워드 검색의 품질은 토크나이저가 정한다. 직접 만든 토크나이저는 말뭉치가 생명이다.
  5. 토큰 기반은 정확한 단어에, 임베딩은 뜻에 강하다. 실무는 둘을 섞는다.
