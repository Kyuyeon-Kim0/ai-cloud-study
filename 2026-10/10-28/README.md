# 2026-10-28 (수) 학습 기록

## 학습 주제

- Tableau에서 지역별 구매 현황을 시각화하고 대시보드로 구성
- Superstore 데이터로 제품별 매출과 수익 분석
- 대시보드 액션과 이미지·마커 데이터를 활용한 상호작용 구성

## 핵심 이해

### 시각화와 대시보드

- 여러 시트의 차트와 요약 정보를 대시보드에 배치해 분석 흐름을 구성합니다.
- 지역 및 제품 관점에서 구매·매출·수익 데이터를 비교하고 패턴을 살펴봅니다.
- 대시보드 액션을 이용하면 선택한 항목을 다른 시트의 필터나 강조 기준으로 연결할 수 있습니다.

### 데이터 연결

- `.twb`는 Tableau 통합 문서이며, 연결된 원본 데이터 파일을 포함하지 않습니다.
- 원본 파일이 다른 위치에 있으면 Tableau에서 데이터 원본 경로를 다시 지정해야 합니다.
- 특히 액션 대시보드는 여러 Excel/CSV 원본에 연결되어 있으므로 필요한 데이터 파일을 함께 준비해야 합니다.

## 실습 내용

- 지역별 구매 현황을 지도와 요약 시트로 표현하고 대시보드 구성
- 시간 흐름 요약과 상세 시트를 결합한 지역별 구매 현황 대시보드 확인
- Superstore 데이터를 이용해 제품별 매출·수익 시각화
- 이미지 및 마커 데이터를 활용한 태블로 액션 대시보드 살펴보기

## 열기 및 데이터 연결

- Tableau Desktop 또는 Tableau Public에서 `.twb` 파일을 엽니다.
- 데이터 연결 오류가 나타나면 통합 문서의 데이터 원본 편집 메뉴에서 해당 Excel/CSV 파일 위치를 다시 지정합니다.
- 이 폴더에는 통합 문서만 있으므로 연결 대상 데이터 파일은 별도로 준비해야 합니다.
