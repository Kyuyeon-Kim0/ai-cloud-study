# 2026-10-02 (금) FastAPI · Docker · K3s 배포 학습 기록

## 학습 주제

- FastAPI를 이용한 간단한 API 서버 구성
- HTML을 이용한 웹 화면 구성
- Dockerfile을 이용한 FastAPI 이미지 생성
- MySQL 네트워크 및 사용자 권한 확인
- Docker 이미지를 K3s에서 사용할 수 있도록 등록
- ConfigMap과 Secret을 이용한 환경 설정 관리
- Deployment와 Pod를 이용한 애플리케이션 실행
- NodePort Service를 이용한 외부 접속
- API 및 HTML 화면 동작 확인

## 실습 구성

```text
사용자 브라우저
      ↓
NodePort Service
      ↓
FastAPI Pod
      ↓
MySQL
      ↓
데이터 조회
```

## 핵심 파일

```text
product-app/
├── main.py
├── requirements.txt
├── Dockerfile
├── templates/
│   └── index.html
└── k8s/
    ├── configmap.yaml
    ├── secret.yaml
    ├── deployment.yaml
    └── service.yaml
```

- `main.py` : FastAPI 서버 및 API 코드
- `index.html` : 사용자에게 보여줄 웹 화면
- `requirements.txt` : Python 라이브러리 목록
- `Dockerfile` : Docker 이미지 생성 방법
- `configmap.yaml` : DB 주소 등 일반 설정
- `secret.yaml` : DB 계정, 비밀번호 등 민감한 설정
- `deployment.yaml` : Pod 실행 및 관리 설정
- `service.yaml` : NodePort를 이용한 외부 접속 설정

## 핵심 개념

```text
소스 코드
   ↓
Docker Image
   ↓
K3s Deployment
   ↓
Pod
   ↓
Service
   ↓
NodePort
   ↓
브라우저 접속
```

- **Docker Image** : 애플리케이션 실행에 필요한 파일을 포장한 것
- **Deployment** : 어떤 이미지로 몇 개의 Pod를 실행할지 관리
- **Pod** : 애플리케이션이 실제로 실행되는 단위
- **Service** : Pod에 안정적으로 접근할 수 있도록 연결
- **NodePort** : 외부에서 K3s 서비스에 접속할 수 있도록 포트를 개방
- **ConfigMap** : 일반 환경 설정 관리
- **Secret** : 비밀번호 등 민감한 설정 관리
