# 2026-10-12 (월) 학습 기록

## 학습 주제

- LLM API와 LangChain
- AI 에이전트와 도구 사용
- 임베딩 기반 검색과 에이전트 방식 비교
- YOLOv8 객체 탐지 및 회의실 이미지 분석

## 핵심 이해

### LLM API와 AI 에이전트

- LLM API를 애플리케이션에서 호출해 질문에 대한 응답을 생성할 수 있습니다.
- 에이전트는 사용자 요청에 따라 등록된 도구를 선택해 활용하고, 결과를 종합해 응답합니다.
- 상품 안내 실습에서 임베딩 유사도 기반 기능 선택과 Agents SDK 기반 도구 선택을 구현해 비교합니다.

### YOLOv8

- 사전학습된 YOLOv8 모델로 이미지와 동영상의 객체를 탐지할 수 있습니다.
- 탐지 결과를 바운딩 박스, 클래스, 신뢰도 등으로 확인하고 시각화합니다.
- 회의실 실습에서는 탐지된 인원수를 규칙으로 분류하고, 에이전트가 집계 정보를 해석하도록 구성합니다.

## 실습 내용

- 같은 상품 안내 과제를 임베딩 방식과 AI 에이전트 방식으로 구현
- YOLOv8로 이미지 및 동영상 객체 탐지
- 회의실 사진의 사람·의자·테이블 탐지 결과를 저장하고 에이전트 해석을 확인
