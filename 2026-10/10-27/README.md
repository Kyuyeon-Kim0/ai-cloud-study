# 2026-10-27 (화) 학습 기록

## 학습 주제

- 탐지·검색 성능 평가 지표와 골드 데이터
- 텍스트 정제, 한국어 형태소 분석, 미등록어(OOV) 처리
- CSV 규칙 검사와 TF-IDF·BM25 근거 검색 통합

## 핵심 이해

### 탐지·검색 평가

- 탐지 결과는 정답 데이터와 비교해 정밀도·재현율·F1 등으로 평가합니다.
- 검색 결과는 정답 문서의 순위와 포함 여부를 기준으로 평가하며, 검색 점수만으로 규칙 적합 여부를 확정하지 않습니다.
- 작은 교육용 표본에서 얻은 점수는 일반적인 성능 보증으로 해석하지 않습니다.

### 전처리와 형태소 분석

- 정규화는 원본 규칙과 식별자를 보존하고, 검색용 텍스트 복사본에 적용합니다.
- 한국어의 표기 변화와 OOV를 살펴보고, 형태소 분석 및 사용자 사전의 활용을 연습합니다.
- 전처리 버전을 기록해 검색 결과와 캐시의 기준을 관리합니다.

### 검사·검색 통합

- 규칙 CSV를 이용한 직접 판정과 검색 후보 제시는 역할을 구분합니다.
- 파이프라인과 API, DB 저장 및 웹 화면을 연결하고 테스트·CI·컨테이너·Helm 구성을 살펴봅니다.
- HTML 정적 검사 결과는 전체 WCAG 적합성 인증을 의미하지 않습니다.

## 실습 내용

- 탐지 및 검색 성능 평가용 지표와 골드 데이터 살펴보기

- CSV 규칙 검사와 근거 검색 통합 애플리케이션 구성
