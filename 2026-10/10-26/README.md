# 2026-10-26 (월) 학습 기록

## 학습 주제

- 웹 규칙 CSV를 이용한 BoW·TF-IDF·BM25 정보 검색
- 하네스와 Codex를 활용한 작업 지침·검증 실습
- 도구, Skill, 워크플로, 계약 검증을 결합한 통합 실습

## 핵심 이해

### 규칙 기반 정보 검색

- BoW와 TF-IDF의 벡터 및 유사도 계산, BM25의 문서 순위 산정 원리를 익힙니다.
- 검색 점수는 공식 적합 판정이 아니며, 검색 결과가 기존 검사 상태를 바꾸지 않습니다.
- 규칙 원본이 바뀌면 검색 인덱스를 다시 만들어야 합니다.

### 하네스와 실행 제어

- 같은 코딩 요청을 하네스 지침 유무에 따라 실행하고, 독립 검증기로 결과를 비교합니다.
- 테스트와 서비스 응답 검증, 도구·Skill·워크플로·계약을 사용해 작업 결과를 점검합니다.
- 지침 파일만으로 파일 시스템 권한이 제한되지는 않으므로 실제 보호에는 권한·샌드박스·승인 절차가 필요합니다.

## 실습 내용

- CSV 규칙 데이터에서 BoW·TF-IDF·BM25 검색 구현과 비교
- Codex 작업 지침의 유무에 따른 주문 보고서 구현 실험
- 주문 데이터의 필터·도구·Skill·워크플로 및 계약 검증 실습
- W3C 검사, 판정 규칙, 정보 검색, 하네스 아키텍처 교안 확인
