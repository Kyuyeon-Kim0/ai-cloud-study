# 주문 보고서 프로젝트 작업 계약

## 목표
`orders.csv`를 읽어 `output/report.csv`에 `total_amount`를 추가한다.
`min_total=5000`인 경우 5,000원 이상인 주문만 출력한다.

## 변경 가능한 곳
- `report.py` (구현 대상)
- `test_report.py` (추가 테스트가 필요한 경우에 한함)

## 변경 금지
- `orders.csv`, `orders.sha256` (원본·무결성 기준)
- 위 프로젝트 경로 밖의 파일, 다른 설정이나 비밀정보

## 완료 조건
- 기본 실행에서 4건, 합계 17,000원
- 최소금액 5,000원 필터에서 O101·O103만 남음
- 중복 주문 ID, 음수 수량을 거부함
- `python -m unittest -v` 실제 실행 결과 보고
- 입력 원본 해시 유지. 실패하면 완료라고 주장하지 않음

## 승인 조건
원본 수정 또는 작업 범위 확장이 필요하면 먼저 이유를 설명하고 승인을 요청한다.

> 이 문서는 Codex가 참고하는 작업 지침이다. OS 권한을 강제로 차단하는 파일은 아니다.
