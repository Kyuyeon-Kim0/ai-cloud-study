04. DF·IDF: 검색어의 희귀성

이 단계가 필요한 이유

왜 필요한가? 모든 문서에 나오는 단어보다 일부 문서에만 나오는 단어가 검색 결과를 구별하는 데 도움이 됩니다.

여기서 얻는 결과: 각 단어의 DF와 BM25 IDF.

IDF(q) = ln(1 + (N − DF(q) + 0.5) / (DF(q) + 0.5))

import math
N = len(docs)
idf = {}
for word in vocab:
    df = 0
    for words in tokenized:
        if word in words:
            df += 1
    idf[word] = math.log(1 + (N - df + 0.5) / (df + 0.5))
print(idf)

09. TF-IDF와 BM25의 차이

이 단계가 필요한 이유

왜 필요한가? 두 방법이 모두 단어 빈도와 희귀성을 사용하지만, 빈도와 문서 길이를 다르게 다루기 때문입니다.

여기서 얻는 결과: 언제 어떤 방식을 선택할지 이해.

비교TF-IDF (참고 자료)BM25 (이번 자료)
희귀성평활화 IDFBM25 IDF
단어 반복TF에 비례 (정규화 전)포화 함수로 증가폭 감소
길이 영향L2 정규화b 파라미터로 길이 보정
주요 출력문서 벡터·코사인 유사도질문에 대한 문서 점수
자기유사도코사인 기준 대각선 1BM25에는 자기유사도 개념이 필수 아님
BM25 점수는 일반적으로 0~1 범위의 유사도 확률이 아닙니다. 검색 질의와 문서 집합에 따라 값이 달라집니다.

10. 전체 Python 코드: 단계별 계산 통합

이 단계가 필요한 이유

왜 필요한가? 앞에서 배운 계산을 라이브러리 없이 직접 검증하면 수식과 출력의 연결을 이해하기 쉽습니다.

여기서 얻는 결과: 복사해 실행할 수 있는 완성 코드.

표준 라이브러리 math만 사용합니다. 컴프리헨션 없이 일반 for문으로 작성했습니다.

import math

docs = ['이미지 alt 속성 확인', '링크 이름 후보 확인', '모호한 링크 목적 검토', '입력 필드 이름 후보 확인', '사내 단독 링크 문구 제한', '사내 화면 표시 레이블 정책', '사내 자세히 문구 제한', '바로가기 문구 제한 제안']

# 1. 토큰화
tokenized = []
for doc in docs:
    tokenized.append(doc.split())

# 2. 단어 사전
vocab_set = set()
for words in tokenized:
    for word in words:
        vocab_set.add(word)
vocab = sorted(vocab_set)

# 3. DF와 IDF
N = len(docs)
idf = {}
for word in vocab:
    df = 0
    for words in tokenized:
        if word in words:
            df += 1
    idf[word] = math.log(1 + (N - df + 0.5) / (df + 0.5))

# 4. 길이 통계
lengths = []
for words in tokenized:
    lengths.append(len(words))
avgdl = sum(lengths) / N
k1, b = 1.5, 0.75

# 5. 질문 검색 함수
def search(question):
    query_words = question.split()
    results = []
    for i in range(N):
        K = k1 * (1 - b + b * lengths[i] / avgdl)
        score = 0.0
        for word in query_words:
            if word not in idf:
                continue
            f = tokenized[i].count(word)
            score += idf[word] * f * (k1 + 1) / (f + K)
        results.append((i + 1, docs[i], score))
    results.sort(key=lambda item: item[2], reverse=True)
    return results

# 6. 실행
for doc_id, text, score in search("링크 이름 확인"):
    print(f"D{doc_id} | {score:.4f} | {text}")
