# README 작성 양식

이 저장소의 README는 두 종류로 작성합니다.

- 날짜 폴더 README: 그날의 학습 주제, 핵심 이해, 실습 목록을 정리합니다.
- 실습 프로젝트 README: 프로젝트를 처음 받은 사람이 설치하고 실행할 수 있도록 안내합니다.

날짜 README에는 프로젝트의 상세 설명을 반복하지 않습니다. 프로젝트 README 링크를 제공하고, 설치·실행·문제 해결처럼 프로젝트별 내용은 하위 README에 작성합니다.

---

## 1. 날짜 폴더 README 양식

파일 위치: `2026-09/09-DD/README.md`

```md
# YYYY-MM-DD (요일) 학습 기록

## 학습 주제

- 주제 1
- 주제 2
- 주제 3

## 핵심 이해

### 주제 1

- 핵심 개념 또는 배운 점
- 핵심 개념 또는 배운 점

### 주제 2

- 핵심 개념 또는 배운 점
- 핵심 개념 또는 배운 점

## 실습 내용

- 실습에서 한 작업
- 실습에서 한 작업

## 실습 파일

| 파일 또는 폴더 | 내용 |
| --- | --- |
| [프로젝트 폴더/](프로젝트 폴더/README.md) | 프로젝트 한 줄 설명 |
| [파일명](파일명) | 파일 한 줄 설명 |

## 실행 방법

- HTML 실습은 브라우저에서 대상 파일을 엽니다.
- Python 또는 PowerShell 실습은 각 프로젝트의 README를 따릅니다.
```

필요한 섹션만 남기고, 해당하지 않는 빈 섹션은 삭제합니다. 강의 시간 기록이 유용한 날에는 `## 강의 시간` 섹션을 `## 학습 주제` 앞에 추가합니다.

## 2. 실습 프로젝트 README 양식

파일 위치: `2026-09/09-DD/프로젝트명/README.md`

```md
# 프로젝트 이름

학습 날짜: YYYY-MM-DD (요일)

프로젝트가 무엇을 하고, 어떤 기술을 연습하는지 1~2문장으로 설명합니다.

## 주요 기능

- 기능 1
- 기능 2
- 기능 3

## 준비 사항

- 운영체제 또는 장비 조건
- Python 또는 Node.js 버전
- API 키·웹캠·인터넷 연결 등 필요한 항목

## 파일 구성

| 파일 또는 폴더 | 역할 |
| --- | --- |
| `app.py` | 실행 진입점 |
| `requirements.txt` | Python 패키지 목록 |
| `templates/` | HTML 템플릿 |

## 설치 및 실행

프로젝트 폴더에서 실행합니다.

```powershell
cd C:\ai-starter\2026-09\09-DD\프로젝트명
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

실행 후 접속 주소 또는 사용 방법을 적습니다.

## 사용 방법 또는 실행 옵션

```powershell
# 자주 쓰는 명령 또는 옵션
python app.py --help
```

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| 패키지를 찾을 수 없음 | 가상환경을 활성화하고 `pip install -r requirements.txt`를 다시 실행 |
| 실행되지 않음 | 현재 폴더, 파일명, 필요한 환경 변수를 확인 |
```

웹 프로젝트라면 실행 주소와 주요 URL/API를 `## 사용 방법 또는 실행 옵션`에 표로 추가합니다. API 키가 필요한 경우에는 `.env.example` 사용법만 기록하고 실제 키는 README·로그·커밋에 포함하지 않습니다.

---

## 작성 규칙

- 제목은 날짜 README에는 날짜와 `학습 기록`, 프로젝트 README에는 프로젝트 이름을 사용합니다.
- PowerShell 명령은 Windows 경로와 `powershell` 코드 블록으로 작성합니다.
- 파일·폴더는 백틱으로 표시하고, 하위 프로젝트는 반드시 해당 README로 링크합니다.
- 실행 전에 필요한 조건, 실행 명령, 종료·접속 방법을 함께 기록합니다.
- 실제로 확인하지 않은 결과나 고정된 API 데이터는 단정적으로 적지 않습니다.
- 민감한 값(API 키, 비밀번호, 개인 경로)은 문서에 넣지 않습니다.
